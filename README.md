# 🛋️ Elite Furniture

A modern, responsive, and elegant furniture website built using **HTML, CSS, Bootstrap, and JavaScript**. This project showcases premium furniture collections with an attractive user interface, smooth animations, and a user-friendly browsing experience.

🌐 **Live Demo:** https://elite-furniture-website.netlify.app/  
📂 **GitHub Repository:** https://github.com/UfaqFatima786/Elite-Furniture

---

## 📖 Project Overview

Elite Furniture is a fully responsive furniture website designed to provide customers with a premium online furniture shopping experience. The website features beautifully designed sections, modern layouts, product showcases, and smooth animations to create an engaging user experience.

---

- 🏠 Modern Home Page
